# Leads

Consulta dos leads disponíveis para contato. É por aqui que a sua campanha do dia é montada.

O recorte é sempre **lead vivo**: não arquivado, em Qualificação ou Negociação, e com telefone
cadastrado. Lead sem telefone não aparece, porque não há como ligar para ele.

- [Endpoint](lead-endpoints.md): parâmetros, paginação e erros.
- [Objeto do lead](lead-object.md): campo a campo, inclusive o que costuma enganar.

::: tip O controle de repetição é seu
O CRM não marca lead como "já entregue". Pedir a mesma página amanhã traz os mesmos leads, menos os
que mudaram de etapa. Guarde do seu lado quem já foi trabalhado.
:::
