# Versão 0.0.4 (31-08-2026)

## Sobre

* <strong>change:</strong> Nova url do ambiente de homologação ```https://api-staging.chavesnamao.com.br/integration/v2```

Prezados,

Informamos que realizamos alterações em nossa infraestrutura interna e, por conta disso, o DNS `homologacao.chavesnamao.com.br` será descontinuado.

A partir desta versão, o ambiente de homologação passa a ser acessado pela nova url:

* <strong>Nova url:</strong> `https://api-staging.chavesnamao.com.br/integration/v2`
* <strong>Url antiga:</strong> `https://homologacao.chavesnamao.com.br/vehicle-integration/v2`

Atenção<br>
Ambas as urls vão continuar funcionando em paralelo até o final do ano, dia <strong>31/12/2026</strong>. A partir desta data, a url antiga `https://homologacao.chavesnamao.com.br/vehicle-integration/v2` pode parar de funcionar.

Por garantia, é melhor já alterar as suas integrações para a nova url, evitando qualquer indisponibilidade quando o DNS antigo for desativado.

O ambiente de produção não sofreu alterações e continua na mesma url.

Recomendamos que os desenvolvedores consultem a documentação atualizada do ambiente de testes [clicando aqui](../01-consideracoes-iniciais/test-environment.md).

Atenciosamente.
