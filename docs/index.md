## Qual delas é a sua

| Você quer                                                        | Use                                                            |
| ---------------------------------------------------------------- | -------------------------------------------------------------- |
| Publicar imóveis no portal a partir do seu sistema                | [XML de imóveis](/xml-documentation/)                            |
| Publicar veículos no portal a partir do seu sistema               | [API REST de veículos](/vehicle-api-documentation/)              |
| Receber os contatos que os seus anúncios geraram                  | [Integração de leads](/lead-documentation/)                      |
| Operar leads do CRM da Chaves na Mão como parceiro                | [API de parceiros](/partner-api-documentation/)                  |

As três primeiras são para quem **anuncia** no portal. A última é para empresas parceiras que
trabalham a carteira de leads junto com o nosso time comercial.
